# Thinkamajig

A lighthearted party word game for 3 to 10+ players, each on their own phone around a table.

- Play it: deployed on Netlify (`public/` + `netlify/functions`).
- Run it locally: `npm install`, then `node dev-server.mjs` and open http://localhost:8888
  (open several browser windows to play as several people).
- Design system: `design-system/thinkamajig/MASTER.md`.
- Design prompts and skills: `prompts/` and `.claude/skills/`.
