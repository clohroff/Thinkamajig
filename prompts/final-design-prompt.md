# The Final Prompt (part 2/2)

From the CreateWithAI video "This Claude Skill Changed UI Design Forever!".
Paste this after your product brief (part 1/2: what the app is and who it's for).

---

Design process, in this exact order:

Step A: Use the ui-ux-pro-max skill to generate a complete design system for this product and save it in the project.

Step B: Use the frontend-design skill to write a design plan that works within that design system, check it against this brief, and apply it to every page. Keep all numbers and small text highly readable.

Step C: Once the app is built, run /impeccable critique, fix what it finds, then run /impeccable polish.

Step D: Use the web-design-guidelines skill to review every page and fix all high and medium severity issues.

Step E: Use the webapp-testing skill to screenshot every page at 390px and 1440px wide, fix every layout problem, and confirm each fix with new screenshots.

Engineering requirements: use React with Tailwind, use realistic sample data so every screen looks populated, and make every page fully responsive.

Work autonomously. Test the app yourself before declaring completion. Do not stop after creating a mockup or partial prototype.
